# FilmIA

**FilmIA: Plataforma Web de Reseñas Cinematográficas con Recomendaciones Inteligentes**

Se trata de un proyecto dedicado a la obtención del título de **Analista Universitario en Sistemas de Información (UTN-FRSF)**, correspondiente a la materia **Seminario Integrador**.

## Delimitación del problema / Fundamentación
Muchas personas invierten demasiado tiempo en elegir qué ver entre la gran cantidad de películas y series disponibles. La falta de recomendaciones realmente personalizadas suele generar elecciones poco satisfactorias.

FilmIA propone resolver este problema mediante una plataforma web con un chatbot inteligente que recomienda contenido en función del historial, valoraciones y preferencias de cada usuario, mejorando la eficiencia y la calidad de elección.

### Objetivo general
Desarrollar una aplicación web integral para gestionar, calificar y recibir recomendaciones personalizadas de películas y series, integrando un chatbot basado en IA.

### Objetivos específicos
- Implementar registro, autenticación y gestión de usuarios.
- Integrar un catálogo actualizado desde una base de datos externa (TMDB).
- Desarrollar reseñas, calificaciones por estrellas (1-10) y listas personalizadas.
- Implementar un chatbot LLM para recomendaciones contextuales y consultas sobre contenido audiovisual.

## Población objetivo
Usuarios casuales del entretenimiento audiovisual que quieran registrar sus visualizaciones y recibir asistencia para elegir su próxima opción de contenido.
