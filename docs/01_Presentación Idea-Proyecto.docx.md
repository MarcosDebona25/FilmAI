| 2\. Título de la propuesta |

| FilmIA: Plataforma Web de Reseñas Cinematográficas con Recomendaciones Inteligentes |

| 3\. Delimitación del problema / Fundamentación |
| :---- |
| En la actualidad, muchas personas dedican tiempo significativo a buscar películas o series que se ajusten a sus gustos, disponibilidad de tiempo y preferencias específicas. Esta búsqueda suele resultar difícil y poco eficiente debido a la gran cantidad de contenido disponible, la diversidad de géneros, y la falta de recomendaciones personalizadas que consideren el historial y las valoraciones individuales del usuario. El problema central que aborda este proyecto es la dificultad para elegir buenas películas o series y el tiempo que se invierte en explorarlas de manera efectiva. Los usuarios a menudo terminan consumiendo contenido por azar o basándose únicamente en listas genéricas, críticas externas o sugerencias superficiales, lo que reduce la satisfacción de la experiencia de entretenimiento. Para resolver esta problemática, el proyecto propone una plataforma web que integra un chatbot inteligente basado en modelos de lenguaje. Este sistema permitirá a los usuarios recibir recomendaciones personalizadas, rápidas y fundamentadas en su historial de visualización, valoraciones y preferencias particulares. Además, la plataforma almacenará y organizará las películas y series vistas por cada usuario, facilitando el seguimiento de su experiencia y mejorando la eficiencia en la selección de contenido. De esta manera, el proyecto no solo busca optimizar el tiempo de búsqueda de entretenimiento, sino también mejorar la calidad de la elección de contenido, ofreciendo una experiencia personalizada, ágil y satisfactoria para cada usuario. |
| **3.1 Objetivo General** |
| Desarrollar una aplicación web integral que permita a los usuarios gestionar, calificar y recibir recomendaciones personalizadas de películas y series, integrando un chatbot basado en inteligencia artificial para mejorar la experiencia del usuario. |
| **3.2 Objetivos Específicos**  |
| Implementar un sistema de registro, autenticación y gestión de usuarios.  Integrar la aplicación web con una base de datos externa (Ej: The Movie Database) para proporcionar un catálogo actualizado de películas y series con información detallada (posters, sinopsis, actores, etc). Desarrollar un sistema completo de calificación por estrellas (1-10, solo valores enteros) con reseñas textuales, gestión de listas personalizadas (pendientes, favoritas, personalizadas) y una interfaz intuitiva para la navegación entre películas, series y perfil de usuario. Implementar un chatbot basado en LLM (accesible únicamente para usuarios autenticados) que analice preferencias, historial y perfil del usuario para generar recomendaciones contextuales, predicciones de compatibilidad y respuestas a consultas específicas sobre contenido audiovisual. |

| 4\. Población |
| :---- |
| Usuarios casuales del mundo del entretenimiento audiovisual que quieran registrar sus  visualizaciones y tener asistencia a la hora de elegir una nueva opción de entretenimiento. |
