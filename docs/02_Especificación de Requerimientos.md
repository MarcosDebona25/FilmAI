### 1. Descripción del Alcance del Problema

Se trata de una aplicación web centrada en el ámbito del entretenimiento audiovisual, más específicamente en películas y series, que permite a los usuarios descubrir, organizar y opinar sobre películas y series. Cada usuario puede crear una cuenta personal, acceder a un catálogo actualizado sincronizado con The Movie Database (TMDB), calificar y reseñar contenidos, y gestionar sus propias listas de favoritos, pendientes, vistas y posibles listas personalizadas.

Además, el sistema incorpora un chatbot con inteligencia artificial que genera recomendaciones personalizadas a partir del historial, las calificaciones y las reseñas del usuario, utilizando un modelo de lenguaje externo al que se le proporcionan datos sensibles de forma anonimizada. También, incluye gestión de usuarios y moderación de reseñas.

Desde el punto de vista técnico, se garantiza el cifrado de la información, la validación constante de sesiones y la compatibilidad con navegadores de escritorio y móviles. El diseño prioriza tiempos de respuesta bajos tanto en la navegación general como en las consultas procesadas por el chatbot.

### 2. Requerimientos Funcionales

- El sistema deberá permitir a los usuarios crear cuentas con credenciales válidas de email, nombre y apellido, fecha de nacimiento, género, nombre de usuario y contraseña.
- El sistema deberá permitir a los usuarios crear cuentas e iniciar sesión mediante autenticación con Google (OAuth 2.0).
- El sistema deberá permitir a los usuarios modificar la información de su perfil personal incluyendo contraseña, nombre de usuario, nombre, apellido y foto de perfil, y mostrar la información actualizada en el momento.
- El sistema deberá permitir a los usuarios dar de baja sus cuentas.
- El sistema deberá permitir a los usuarios autenticarse y acceder a sus cuentas usando credenciales válidas.
- El sistema deberá permitir a los usuarios visualizar la información completa de su perfil y detalles de cuenta.
- El sistema deberá permitir a los usuarios calificar una serie/película con la opción de añadir una reseña.
- El sistema deberá permitir a los usuarios modificar el contenido (texto y/o calificación) de sus propias reseñas.
- El sistema deberá permitir a los usuarios eliminar permanentemente sus propias reseñas y/o calificaciones.
- El sistema deberá permitir la navegación entre secciones (Inicio, Buscar, Listas) mediante la barra de navegación. El acceso al perfil se realiza a través del avatar del usuario.
- El sistema deberá exponer el catálogo de películas y series actualizado desde la fuente externa integrada (The Movie Database).
- El sistema deberá registrar y almacenar, por usuario, el historial de visualizaciones, calificaciones y reseñas.
- El sistema deberá aplicar control de acceso por roles (usuario, administrador) para las operaciones protegidas.
- El sistema deberá validar que las calificaciones estén en el rango permitido (1-10).
- El sistema deberá permitir a los usuarios buscar películas y series por nombre.
- El sistema deberá tener listas predeterminadas para favoritos, pendientes y visto.
- El sistema deberá permitir al usuario eliminar películas o series de cualquiera de sus listas (predeterminadas o personalizadas).
- El sistema deberá proporcionar un chatbot accesible desde la página de inicio para las consultas de usuarios.
- Mientras el usuario esté autenticado, el sistema deberá permitir acciones de gestión de perfil, creación/modificación de listas, y gestión de reseñas.
- Mientras el chatbot esté procesando una solicitud de recomendación, el sistema deberá mostrar un indicador de progreso y permitir la cancelación de la petición.
- Si el usuario intenta publicar o modificar una reseña sin calificar (o quitando la calificación existente) o con contenido inválido, entonces el sistema deberá denegar la publicación o modificación.
- Si el usuario ingresa credenciales incorrectas para el inicio de sesión, entonces el sistema deberá notificar el error.
- Cuando el usuario realice una consulta mediante el chatbot, el sistema deberá procesar la consulta y devolver una respuesta basada en el historial del usuario, sus reseñas y el dominio almacenado.
- Cuando el usuario cree o modifique listas personales, el sistema deberá actualizar y mostrar dichas listas en la sección de Listas.
- Cuando el usuario marque una película/serie como vista, el sistema deberá registrarla en su historial.
- Cuando el usuario busque películas/series por nombre, el sistema deberá devolver los resultados coincidentes con paginación y, si no hay coincidencias mostrar el resultado vacío con un aviso.
- Cuando el usuario publique o modifique una reseña, el sistema deberá almacenar la reseña y actualizar las reseñas en la sección "Mis reseñas".
- Cuando el usuario elimine una reseña, esta deberá ser eliminada de la sección "Mis reseñas".
- Cuando el usuario cree su cuenta, el sistema deberá mandar un correo de confirmación.
