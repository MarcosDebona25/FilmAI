# Commit Type Examples

| Type     | Description                                                    | Example                                                        |
| -------- | -------------------------------------------------------------- | -------------------------------------------------------------- |
| feat     | A new feature for the user.                                    | `feat(cart): add ability to save items for later`              |
| fix      | A bug fix for the user.                                        | `fix(user-profile): resolve issue with profile picture upload` |
| chore    | Changes that don't modify `src` or `test` files.               | `chore(deps): update dependencies to latest versions`          |
| docs     | Documentation-only changes.                                    | `docs(readme): update examples section for clarity`            |
| style    | Changes that do not affect the meaning of the code.            | `style(app): format code with Prettier`                        |
| refactor | A code change that neither fixes a bug nor adds a feature.     | `refactor(auth): simplify authentication middleware`           |
| perf     | A code change that improves performance.                       | `perf(api): optimize database queries`                         |
| test     | Adding or updating tests.                                      | `test(userService): add unit tests for user service`           |
| build    | Changes that affect the build system or external dependencies. | `build(ci): update Travis configuration for automated tests`   |
| ci       | Changes to CI configuration files and scripts.                 | `ci(github-actions): add GitHub Actions workflow for CI`       |
| revert   | Reverts a previous commit.                                     | `revert: "feat(dashboard): add user analytics widget"`         |
